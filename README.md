# KOLPO HOUSE

An editorial React and Vite website for KOLPO HOUSE, an independent creative studio.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Project structure

- `src/components` — website sections and reusable UI
- `src/config` — site content and asset registry
- `src/hooks` — scroll and interaction behavior
- `public/assets` — website images and video assets

The site supports responsive layouts, light and dark themes, reduced motion, and scroll-based animation.
